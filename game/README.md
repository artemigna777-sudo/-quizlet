# «Стёртый город» — игра, которую придумывают зрители

3D-хоррор на выживание от первого лица, в браузере (телефон и компьютер). Стиль — «как на PS1»: низкое разрешение,
«дрожащие» вершины, туман. Всё, что решили зрители в сериях 1–7, уже в игре: заброшенный город, герой без памяти
с надписью «УБЕЙ СТРЕЛКА» на ладони, пёс со шрамом, город стирает людей, а пёс от стирания защищает.

Концовки (их три) в этом открытом репозитории не хранятся.

## Что есть в версии 0.1
- Город 5×5 кварталов: дома, улицы, мигающие фонари, луна, пепел; на границе — стена помех (дальше всё стёрто).
- Игрок: ходьба и бег со столкновениями, фонарик, ладонь с надписью (Q / ✋).
- Пёс: идёт рядом; чует ближайшее воспоминание и ведёт к нему по улицам; ждёт и лает, если игрок отстал.
- Стирание: дальше 8 м от пса растёт «давление» — мир сереет, глохнет, идут помехи; на 100% игрока стирает,
  возврат к последнему воспоминанию.
- Три воспоминания; у найденного загорается окно ближайшего дома. Прогресс хранится на устройстве.
- Фигура в противогазе иногда стоит под дальним фонарём и исчезает, если подойти (пока только пугает).
- Звук синтезируется в браузере: ветер, шаги, лай, помехи.

## Управление
- Компьютер: WASD — идти, мышь — смотреть, Shift — бежать, F — фонарик, Q — ладонь, E — взять, Esc — пауза.
- Телефон: левая половина экрана — идти (сильный наклон — бег), правая — смотреть; кнопки 🔦, ✋, «Взять».

## Разработка
```
cd game
npm install
npm run dev        # игра на http://localhost:5173
npm test           # тесты логики (столкновения, стирание, путь пса по улицам)
npm run build      # сборка в dist/
node tests/smoke.cjs   # проверка в браузере со снимками (нужен Playwright)
```
Файлы: `src/world.ts` — город, `player.ts` — игрок, `dog.ts` — пёс, `logic.ts` — логика без графики,
`memories.ts` — воспоминания, `shooter.ts` — фигура вдали, `audio.ts` — звук, `main.ts` — главный цикл.

Публикация: `.github/workflows/game.yml` собирает игру и выкладывает на GitHub Pages при пуше в `main`
(один раз включить: Settings → Pages → Source: GitHub Actions).
