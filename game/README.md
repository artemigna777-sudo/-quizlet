# «Стёртый город» — игра, которую придумывают зрители

3D-хоррор на выживание от первого лица, в браузере (телефон и компьютер). Стиль — «как на PS1»: низкое разрешение,
«дрожащие» вершины, туман. Всё, что решили зрители в сериях 1–7, уже в игре: заброшенный город, герой без памяти
с надписью «УБЕЙ СТРЕЛКА» на ладони, пёс со шрамом, город стирает людей, а пёс от стирания защищает.

Концовки (их три) в этом открытом репозитории не хранятся.

## Что есть в версии 0.1
- Город 5×5 кварталов: дома, улицы, мигающие фонари, луна, пепел; на границе — стена помех (дальше всё стёрто).
- Игрок: ходьба и бег со столкновениями, фонарик, ладонь с надписью (Q / ✋).
- Пёс: идёт рядом; чует ближайшее воспоминание и ведёт к нему по улицам; ждёт и лает, если игрок отстал.
- Стирание: дальше 8 м от пса растёт «давление» — мир сереет, глохнет, идут помехи; на 100% игрока стирает,
  возврат к последнему воспоминанию.
- Три воспоминания; у найденного загорается окно ближайшего дома. Прогресс хранится на устройстве.
- Фигура в противогазе иногда стоит под дальним фонарём и исчезает, если подойти (пока только пугает).
- Звук синтезируется в браузере: ветер, шаги, лай, помехи.

## Управление
- Компьютер: WASD — идти, мышь — смотреть, Shift — бежать, F — фонарик, Q — ладонь, E — взять, Esc — пауза.
- Телефон: левая половина экрана — идти (сильный наклон — бег), правая — смотреть; кнопки 🔦, ✋, «Взять».

## Разработка
```
cd game
npm install
npm run dev        # игра на http://localhost:5173
npm test           # тесты логики (столкновения, стирание, путь пса по улицам)
npm run build      # сборка в dist/
node tests/smoke.cjs   # проверка в браузере со снимками (нужен Playwright)
```
Файлы: `src/world.ts` — город, `player.ts` — игрок, `dog.ts` — пёс, `logic.ts` — логика без графики,
`memories.ts` — воспоминания, `shooter.ts` — фигура вдали, `audio.ts` — звук, `main.ts` — главный цикл.

Публикация: `.github/workflows/game.yml` собирает игру и выкладывает на GitHub Pages при пуше в `main`
(один раз включить: Settings → Pages → Source: GitHub Actions).

## Версия 0.2 — двор (вертикальный срез), 12.11.2026

Центральный квартал — двор с четырьмя домами, в которые можно зайти.

- **Дома с интерьерами**: комнаты, обои, окна, ковры, лампы, мебель из готовых моделей Poly Haven (список — `CREDITS.md`).
- **Истории жильцов** (`src/story.ts`): Нина Сергеевна (учительница музыки), баба Зоя (кормила дворовых кошек),
  Гена и Люда (лодка в гараже), Тёма (шпионский журнал). Истории рассказаны вещами — расписания, тетрадь, чеки,
  записки — и пересекаются между соседями.
- **«Проявить комнату»**: дальняя комната каждого дома стёрта — серые силуэты за дверью из помех. Она возвращается,
  когда принесёшь к двери вещь хозяина. Вещи идут по кругу: миска → ключ от гаража → бинокль → метроном.
- **Пёс ведёт по запаху**: к дому, где лежит следующая вещь, а с вещью в руках — к двери её хозяина.
- Воспоминаний теперь 7: три на улицах и четыре во дворе. Прогресс (найденное, вещь в руках) сохраняется.

Проверки: `npm test` (логика цепочки вещей и тексты), `npm run build && node tests/smoke.cjs` (сценарий в браузере,
снимки в `tests/shots/`).

Что дальше: остальные механики (день и ночь, голоса прошлого, подсказки на стенах), детали улиц, следующие дворы.

## Версия 0.3 — выживание, день и ночь, враги, большой город, 12.11.2026

По замечаниям Артёма к версии 0.2.

- **Город 7×7 кварталов, районы разные** (`src/world.ts`): двор в центре, вокруг панельные девяти- и пятиэтажки,
  дальше хрущёвки, магазины (аптека, почта, хлеб…), школа, гаражи, парки, по краям — частный сектор с деревянными
  домами, заборами и поленницами. На улицах машины, остановки, деревья, скамейки, качели.
- **День и ночь** (`src/survival.ts`): сутки — 12 минут (день 7, ночь 5). Днём город цветной, ночью — тёмный,
  горят фонари, стирание в полтора раза сильнее. Часы — в углу экрана.
- **Выживание**: голод и жажда. Еда и вода лежат в домах жильцов (у каждого своё: килька у бабы Зои, сухарики у Тёмы),
  в магазине «Продукты» (в него можно зайти) и в ящиках на улицах. Клавиши 1 и 2 — поесть и попить.
- **Здоровье без полоски**: чем его меньше, тем серее экран. Сытый герой понемногу восстанавливается.
- **Оружие** (`src/combat.ts`): топор — в пне во дворе; автомат и патроны — у поста милиции на юго-западе
  (подсказка — в тетради под кассой магазина). Левая кнопка мыши или пробел — удар, X — сменить оружие.
- **Ночные враги**: «эхо» — копии Стрелка, идут на звук шагов (бег слышно издалека), в дома не заходят, на рассвете
  рассыпаются; «крикун» стоит неподвижно, пока на него не посветишь фонариком, потом бросается. Пёс рычит, когда они
  рядом, и может вцепиться в копию. От копии иногда остаются припасы.
- **Вещи в руках**: у каждой своё действие у стёртой двери — поставить миску, открыть ключом, завести метроном,
  посмотреть в глазок через бинокль (комната видна сквозь помехи). С биноклем в руках можно смотреть вдаль (V).
- **В комнатах больше вещей**: книги на полках, посуда на столах, припасы.
- **Телефон — только горизонтально**: в вертикальном положении игра просит повернуть телефон.

Не проверено на настоящем телефоне: плавность большого города, кнопки на экране, поворот экрана.

## Версия 0.4 — детализация двора, 12.11.2026

Артём попросил игру подетальнее; проверяет на iPhone 16 Pro. Потом игра пойдёт приложением в RuStore.

- **90 готовых моделей** (было 32): кресла, диваны, плита, чайник, напольные часы, стеллажи, посуда, картины,
  подушки, цветы в горшках, инструменты, касса в магазине. В каждой комнате двора теперь по 15–25 предметов.
- **Тени**: от солнца и луны на улице, от фонарика — в комнатах.
- **Качество** «высокое» (чётче, с тенями) и «обычное». Игра меряет скорость в первые 5 секунд и сама понижает
  качество, если кадров мало; переключатель — в паузе.
- Исправлено: сквозь полы комнат местами просвечивал асфальт.

Не проверено на телефоне: скорость загрузки (модели весят 17 МБ) и плавность с тенями.
