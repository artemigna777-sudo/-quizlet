# «Игру делают зрители» — сериал для TikTok

Формат: игру с нуля делает нейросеть (Claude Code, модель Opus 5.5), а всё, какой она будет, — жанр, героя,
мир, музыку, концовку — выбирают зрители в комментариях. Одна серия — один выбор, побеждает комментарий
с наибольшим числом лайков.

## Серия 1 — вступление (`ep01/`)

Готовый ролик: `ep01/mp4/ep01.mp4` — 1080×1920, 30 к/с, 52 с, −14 LUFS.
`ep01/mp4/ep01-bez-muzyki.mp4` — только голос и звуки, если музыку хочется взять из библиотеки TikTok.

Сценарий (`ep01/lines.mjs`):
1. «Привет! Сегодня мы начинаем делать игру. С нуля, с помощью нейросети.»
2. «Но есть одно правило: какой будет эта игра — решаете вы.»
3. «Жанр, главный герой, мир, музыка, даже концовка — всё выбирают зрители, прямо в комментариях.»
4. «А код пишет нейросеть: Claude Code, на модели Opus 5.5.»
5. «Я сам не напишу ни строчки кода. Только передаю ему ваши решения.»
6. «Каждая серия — один выбор. Побеждает комментарий, у которого больше всего лайков.»
7. «Думаете, ничего не выйдет? Так я уже сделал целую игру для подготовки к экзамену ПДД. Ссылка в профиле.»
8. «Итак, первый выбор: какой жанр?» — четыре плитки. Плитки 1–3 по очереди раскрываются зумом на весь экран:
   - «1 — гонки: нитро, дрифт и 300 на спидометре!» — неоновая трасса, обгон на нитро, дрифт с дымом, спидометр до 300;
   - «2 — хоррор: темно, тихо… и кто-то стоит у тебя за спиной.» — гаснет свет, фонарик, фигура в конце коридора,
     музыка замолкает, скример;
   - «3 — выживание: остров, костёр и одна ночь до рассвета.» — остров под луной, костёр, глаза волков, вой,
     таймер до рассвета;
   - «4 — своё. Пиши цифру в комменты!» — плитка без сцены, потом крупное «Пиши цифру в комменты».
9. «Подпишись, чтобы увидеть, что из этого выйдет.»

Первые 8 секунд — новый кадр каждые полсекунды: «ПРИВЕТ!» из разлетающихся букв, монитор с «сделай игру»,
мелькающие превью жанров, «С НУЛЯ», нейросеть с импульсами, сирена «ПРАВИЛО №1», барабан жанров и взрыв «ВЫ».

Картинка — моушн-дизайн кодом (HTML + SVG + GSAP, рендер HyperFrames) в стиле прошлых роликов «Курьера ПДД»:
тёмный фон, оранжевый акцент, крупные субтитры с подсвеченными словами, тряска и вспышки на ударных словах.
Кадр города и значок — из игры «Курьер ПДД». Музыка (124 BPM, дроп на голосовании) и звуки синтезированы кодом.
Субтитры и важное держатся выше 1500 px и левее правой колонки кнопок TikTok.

### Озвучка

Черновая — Fish Audio (бесплатная модель `s2.1-pro-free`, голос «Энергичный Рассказчик»): `node voice.mjs`.
Чтобы взять голос из ElevenLabs: озвучь реплики из `lines.mjs` (поле `say`) по одной и положи их как
`ep01/voice/l1.mp3` … `l9.mp3`. Монтаж подстраивается под длину каждой реплики и паузы в ней сам.

Файлы: `build.mjs` — сцены и монтаж, `genres.mjs` — мини-сцены жанров, `audio.mjs` — музыка и звуки, `lines.mjs` — текст.

### Пересобрать

Нужны Node.js 22, ffmpeg и Chromium.

```
sh ep01/render.sh      # node build.mjs → рендер HyperFrames → сведение звука
```

Только кадры для проверки: `node ep01/build.mjs && cd ep01/out && npx -y hyperframes@0.8.119 snapshot . --at 1,8,16`.

Шрифты Montserrat, Russo One, PT Mono — SIL OFL (`ep01/assets/fonts/OFL.txt`).

## Серия 2 — выбор места (`ep02/`)

Готовый ролик: `ep02/mp4/ep02.mp4` — 1080×1920, 47 с, −14 LUFS (и `ep02-bez-muzyki.mp4`).
Победил вариант зрителей: выживание + хоррор.

1. «Привет! Сегодня мы продолжаем делать нашу игру — по вашим комментариям.» — буквы, штамп «СЕРИЯ 2»,
   монитор «загрузка сохранения», комментарии затягивает в игру.
2. «В прошлый раз вы выбирали жанр. И победил… ваш вариант: выживание + хоррор!» — рулетка по плиткам серии 1
   останавливается на «Своё», корона, комментарий «выживание + хоррор».
3. «Значит, нужно добыть еду, не замёрзнуть и дожить до утра. А в темноте за тобой кто-то охотится.» —
   остров с костром, «+ ХОРРОР», тьма сгущается, у кустов фигура с красными глазами.
4. «Код всё так же пишет нейросеть, Claude Code. А решаете — вы.» — план игры в терминале, «ВЫ».
5. «Выбор №2: где всё происходит?» — мини-сцены на весь экран:
   - лагерь: качели качаются сами, в окне корпуса проходит тень, свет гаснет;
   - метро: последний поезд уходит в тоннель, свет мигает, из тоннеля идёт фигура;
   - космос: утечка кислорода, тревога, метка на радаре, тень за иллюминатором;
   - «своё» и «Пиши цифру в комменты».
6. «А пока ждёте — моя прошлая игра… Курьер ПДД…» — телефон с игрой, «ссылка в профиле».
7. «Подпишись…»

Сборка: `sh ep02/render.sh`. Файлы: `build.mjs`, `places.mjs` (мини-сцены мест), `genres.mjs`, `audio.mjs`, `lines.mjs`.

YouTube: загружено 05.11.2026 на канал «Теория без нервов» — https://youtube.com/shorts/TQKWzrsSO4E (описание — `ep02/youtube.json`).

## Серия 3 — выбор героя (`ep03/`)

Готовый ролик: `ep03/mp4/ep03.mp4` — 1080×1920, 47 с, −14 LUFS (и `ep03-bez-muzyki.mp4`).
Итог серии 2: многие написали «4», а топ по лайкам — «заброшенный город с кучей заброшенных домов».

1. «Привет! Мы продолжаем делать нашу игру — по вашим комментариям.»
2. Итоги: плитки серии 2, вокруг «Своё» вылетают «4», сердце, комментарий-победитель с короной.
3. Город-призрак: пустая улица, выбитые окна, мигающий фонарь, вороны — камера наезжает на единственное горящее окно.
4. План игры v0.2 в терминале, «решаете — ВЫ».
5. «Выбор №3: кто главный герой?» — мини-сцены на весь экран:
   - курьер: навигатор ведёт по ул. Тихой, 13 — улицы гаснут, «АДРЕС НЕ НАЙДЕН»;
   - блогер: стрим из заброшки, чат взрывается «СЗАДИ!!!», в двери фигура, помехи;
   - пёс: нюхает след, «собачье зрение» — светящиеся следы и призрак;
   - «своё» и «Пиши цифру в комменты».
6. «Курьер ПДД» перед концом, 7. подписка.

Сборка: `sh ep03/render.sh`. Сцены — `town.mjs`. Описание для YouTube — `ep03/youtube.json`.
