# «Игру делают зрители» — сериал для TikTok и YouTube

## Правила (от Артёма)
- **Каждую готовую серию сразу загружать на YouTube** (решение Артёма 06.11.2026), не спрашивая отдельно:
  1. положить описание в `epNN/youtube.json` (название до 100 знаков с `#Shorts`, в описании ссылка
     `https://artemigna777-sudo.github.io/Pdd.game/?ref=youtube`);
  2. `cd ../Pdd.game && npx tsx trailer/youtube/upload.ts ../-quizlet/epNN/mp4/epNN.mp4 ../-quizlet/epNN/youtube.json`
     (ключи — переменные окружения YT_CLIENT_ID, YT_CLIENT_SECRET, YT_REFRESH_TOKEN; канал «Теория без нервов»);
  3. записать ссылку в README и напомнить Артёму: видео загружается скрытым, открыть доступ в YouTube Studio.
- Структура серии: «Привет, продолжаем делать игру по вашим комментариям» → итог прошлого выбора → что это значит
  для игры → Claude Code пишет код, решаете вы → новый выбор (плитки 1–3 раскрываются мини-сценами, 4 — «своё»)
  → «Курьер ПДД» перед концом → подписка.
- Озвучка: черновая Fish Audio (`node voice.mjs`), можно заменить файлами из ElevenLabs.

## Игра «Стёртый город» (`game/`) — видение Артёма (12.11.2026)
- **Масштаб:** большой объёмный мир «как в The Last of Us» — разные районы, дворы, переулки, интерьеры; много предметов,
  с которыми можно взаимодействовать. Сюжет — около 20 часов. Строится по частям: район за районом, сначала один двор,
  сделанный по-настоящему хорошо («вертикальный срез»).
- **Детализация:** стиль PS1 остаётся, но мир не пустой: дома заполнены мебелью и вещами, ничего «под копирку».
  Готовые модели — Poly Haven и Quaternius (CC0), всё чужое записывать в `game/CREDITS.md`.
- **Истории жильцов:** в каждом доме жила своя семья со своей историей. Правило: не рассказывать, а показывать вещами —
  списки, квитанции, записки, детские журналы; конкретные бытовые детали, одна деталь, которая переворачивает историю;
  истории соседей пересекаются. Никакого «нейрослопа» (общих слов про тьму и отчаяние). Истории показывать Артёму пачками.
- **Механики (согласованы):** «проявить комнату» — стёртая комната возвращается, когда вернёшь вещь хозяина;
  пёс ведёт по запаху вещи; день и ночь (ночью стирание сильнее и ходит Стрелок); голоса прошлого (кассеты,
  автоответчики); подсказки на стенах почерком героя. Карта-блокнот — под вопросом.
- **Секретность:** концовок три, зрителям не раскрывать. Концовки и главные повороты сюжета в этот открытый
  репозиторий не записывать (только в закрытый репозиторий, когда Артём его создаст).
- Без «да» Артёма крупные изменения направления не начинать; ролик очередной серии делать только после того, как
  Артём расскажет итог голосования.
